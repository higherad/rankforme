- 서비스명(가제): 랭포미 / RankForMe / 약칭 RFM

## 파일
- 배포 예정: GitHub `higherad/rankforme`(Public, Pages) → `rankforme.kro.kr`(CNAME 파일 포함). 로컬 폴더 `HigherAD Code/RankForMe` (예전 `rank-app`은 잠겨서 복사로 이전 — 삭제 대상)
- `index.html` 프로토타입 전체. 브라우저 저장(localStorage) 사용 안 함 — 데모 데이터는 새로고침하면 처음 상태
- 기획 전달하기: 기획 중 메뉴마다 이름+내용 저장 → 모두가 봄. Firebase RTDB(higherad-b9d62) `rfm/notes/{메뉴키}/{push id}={a,t,ts}`, 규칙은 누구나 읽기·새 글만(수정·삭제는 관리자 토큰으로만). 전체 메뉴 → "전달된 기획 모아보기"(전체 복사)
- 전체 메뉴 정의 = `index.html`의 `TREE`(그룹 8개). `go` 있으면 구현된 화면, 없으면 '기획 중' 페이지(`#/m/키`) + 세부 기획 메모(localStorage `notes`, 전체 복사 기능)
- `manifest.json`·`sw.js`·`icon-*.png` PWA 설치용 — 서비스워커·설치는 http(s)에서만 동작(file:// 더블클릭은 화면만)

## 사용자 요구 기능 (확정)
- 조회 3종: 플레이스 / 쇼핑 / 블로그
- AI: 조회용 정보 자동 등록(URL+키워드), 질의응답
- 스케줄 알림: 설정 시각에 `키워드 | 업체명 | 순위` 형식으로 문자·카톡·사이트 내 알림
- 메뉴 커스텀(유저가 원하는 메뉴 구성)
- 무료 버전: 조회 시 광고 → 광고 닫으면 데이터 표시
- 모바일 친화 + 앱처럼 사용(스토어 등록은 필수 아님)

## 프로토타입에 넣은 편의 기능
- 홈 위젯(요약·바로조회·변동 큰 키워드·다음 알림·즐겨찾기) 켜고 끄기
- 하단 메뉴 켜기/끄기·순서 변경(모바일은 앞 4개 + 더보기), AI 플로팅 버튼 토글
- 키워드 상세: 30일 그래프, 상위 5 경쟁 현황, 메모, 즐겨찾기, 공유, 재조회, 알림 바로 설정
- 그룹 필터·검색·정렬, CSV 내보내기/일괄 등록, 다크모드(시스템 연동)
- 알림 조건: 매번 / 변동 시 / 하락 시 / N위 밖, 시간 여러 개·N시간마다 프리셋·요일, 채널별 미리보기(알림톡·문자·푸시), 테스트 발송, 받은 알림함
- AI(규칙 기반 데모): URL 인식→등록, 키워드 순위 질문, 상승/하락/TOP10/요약, 자연어 알림 예약("평일 9시 카톡으로"), 연관 키워드 추천→원탭 등록
- 요금제 안: 무료(광고·20개) / PRO 9,900원 / BIZ 29,000원 — 금액·한도는 가안

## 실서비스 전환 시 결정 필요
- 조회 엔진: 네이버 수집 방식·차단 대응·조회 단가
- 알림톡: 카카오 비즈채널·템플릿 심사 / 문자: 발송 대행사·단가 → 요금제 포함 수량
- 광고: 네트워크(애드핏·애드센스) 전면 광고 정책 허용 여부
- AI: LLM 함수 호출(등록·조회·알림예약)로 교체
- 백엔드·DB·로그인(카카오 로그인 유력) 스택 미정

## 디자인
- 기존 파랑 디자인(Pretendard, #3b5bfd) 유지 — 종이색·형광펜 리디자인 시도했으나 사용자가 이전 것을 선호해 되돌림
- PC 사이드바 상단에 "랭포미 / RankForMe" 타이틀, 모바일은 홈 헤더에 로고
- 플로팅 버튼 문구: "AI 활용하기"
- 하단 마지막 탭 이름: "전체 메뉴"
- 메뉴 구조: 그룹(바로조회·플레이스·쇼핑·블로그·키워드·알림AI·관리·도구·고객센터) → 하위 메뉴
  - 하위 메뉴 1개인 그룹(바로 조회)은 펼침 없이 바로 이동
  - PC: 사이드바 그룹 클릭 시 펼침(현재 그룹 자동 펼침), 기획 중 메뉴는 회색 점 표시
  - 모바일: 하단 탭 = 그룹(앞 4개, 메뉴 편집에서 변경), 탭하면 첫 하위 메뉴로 이동 + 상단 가로 칩으로 하위 메뉴 전환
  - 전체 메뉴 화면: 그룹별 펼침 카드 + 검색

## 메뉴 그룹 (전체 메뉴)
바로 조회 / 플레이스 / 쇼핑 / 블로그·콘텐츠 / 검색·키워드 / 알림·AI / 관리 / 도구 / 고객센터·내 정보
- 구현됨: 플레이스·쇼핑·블로그 순위 체크, 바로 조회(독립 메뉴 `#/once`, 플레이스·쇼핑·블로그 3종 + 홈 위젯, 같은 quickCard 공유), 알림 예약·받은 알림·채널, AI 비서, 엑셀 입출력, 요금제
- 나머지는 기획 중 — 각 페이지에 예시 데이터 화면(`DEMO`, 가짜 데이터) + 기획 전달하기. 세부 내용 정해지면 해당 메뉴부터 실제 화면 구현
- 글자 수 세기·키워드 조합기는 예시 화면에서 실제 동작
